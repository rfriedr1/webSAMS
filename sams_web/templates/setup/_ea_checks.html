Check standards

The material measured for the daily check, with its reference value and the pass window. A check passes when every certified element is inside min … max (limits included). Leave an element blank if the standard does not certify it. Gauge step is how far the needle moves per mouse/arrow step on the entry strip. Values are copied onto each logged check, so changing them later never rewrites history. Clear the key to remove a standard (not possible once checks were logged with it).
