Reference for key navigation and input shortcuts in SAMS Web.

Magic Nav

Magic Nav is the quick jump field in the top bar. Enter an identifier and press Open to navigate directly to the related detail page.

Magic commands start with / (for example /prep).

For preparation and target details, use dotted numeric IDs: sample.prep (for example 45230.1) and sample.prep.target (for example 45230.1.1).

Settings

The Settings page is the central place for system-level configuration values that should be changeable without editing code.

  • Standard Inventory Thresholds: controls the warning colors used on the dashboard standard indicators and mini-bars.
  • Graphitization Systems: controls the list of selectable systems used in the Graphitization Bench batch builder.
  • Storage: settings are saved in the shared setup data file and are applied when the related pages are loaded.

Use one line per entry for graphitization systems. These values are used to build batch names in the form graph_YYMMDD_system.

Command Palette Shortcut

Use Command + K on macOS (or Ctrl + K on Windows) to open the command palette from anywhere in the app.

  • Type to search: filters available navigation targets and actions shown in the main navigation area.
  • Arrow keys: move through the suggestions.
  • Enter: open the selected item.
  • Escape: close the command palette.
  • Cmd/Ctrl + K again: toggles the command palette closed.

Detail Page Keyboard Shortcuts

These shortcuts are active on any detail page (sample, preparation, target, project, submitter). They're suppressed while typing inside an input or textarea, with one exception: Save works even while typing.

  • e  — toggle edit mode (same as clicking Edit / Cancel).
  • Esc  — cancel edit mode (when in edit mode).
  • Ctrl + S (or Cmd + S)  — save changes.
  • [  or  j  — open the previous record.
  • ]  or  k  — open the next record.
  • ?  — show this list as an overlay on the current page.

The ? overlay is generated from the same source as this list, so it stays in sync if shortcuts change.
